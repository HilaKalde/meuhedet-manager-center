# מרכז הניהול במאוחדת – לומדה למנהלים חדשים

לומדה אינטראקטיבית בעיצוב "webpage" (במה 1280×720, RTL), שתומר בהמשך לקובץ Storyline.

## מבנה

- `HTML/index.html` – הלומדה (קובץ יחיד: HTML, CSS, JS).
- `HTML/assets/` – תמונות, לוגואים ורקעים שהלומדה משתמשת בהם. יש לשמור אותה ליד `index.html`.
- `סביבת הלמידה למנהלים חדשים V4.pptx` – התסריט.
- קבצי ה-PNG בתיקייה הראשית – עיצובי ההשראה.

## הרצה

פתחו את `HTML/index.html` בדפדפן. לחלופין, הריצו שרת מקומי:

```powershell
powershell -ExecutionPolicy Bypass -File .claude/serve.ps1
```

ואז היכנסו ל-http://localhost:8765

## קישורים להשלמה

הקישורים החיצוניים (שאלון אישי, מצגת אסטרטגיה, קובץ עזר לתכנית עבודה, נוהל רכש) מוגדרים באובייקט `LINKS` בקוד ומחכים לכתובות אמיתיות.

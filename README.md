# מרכז הניהול במאוחדת – לומדה למנהלים חדשים

לומדה אינטראקטיבית בעיצוב "webpage" (במה 1280×720, RTL), שתומר בהמשך לקובץ Storyline.

## הגרסה העדכנית

`HTML/index.html` – הגרסה העדכנית של הלומדה, כפי שיוצאה מ-Claude Design.
זהו קובץ עצמאי: כל הקוד והתמונות ארוזים בתוכו, והוא לא תלוי בקבצים אחרים (מלבד הגופן מ-Google Fonts).
אפשר לפתוח אותו ישירות בדפדפן.

## קבצים נוספים

```
HTML/
├── index.html        הלומדה (ייצוא Claude Design, עצמאי)
├── css/styles.css    ┐
├── js/main.js        ├ הגרסה הקודמת, המפוצלת – לפני העבודה ב-Claude Design
└── assets/           ┘ (index.html הנוכחי לא משתמש בהם)
```

- `סביבת הלמידה למנהלים חדשים V4.pptx` – התסריט.
- קבצי ה-PNG בתיקייה הראשית ובתיקייה `רובוט/` – עיצובי ההשראה והתמונות שנוצרו לגרסה הנוכחית.

## הרצה

פתחו את `HTML/index.html` בדפדפן. לחלופין, הריצו שרת מקומי:

```powershell
powershell -ExecutionPolicy Bypass -File .claude/serve.ps1
```

ואז היכנסו ל-http://localhost:8765
